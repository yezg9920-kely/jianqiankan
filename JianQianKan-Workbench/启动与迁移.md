# 剪前看看 · Windows / macOS 电脑工作台

1. 安装 **Node.js 22 或以上版本**（包含 npm），完整解压到自己可写的目录。使用 GitHub 源码也是进入同一个项目目录操作。
2. **Windows**：双击 **Start Workbench.cmd**。**macOS**：双击 **打开剪前看看工作台.command**。首次启动会联网安装 npm 锁定的依赖；如果目录里只有源码，会先构建页面。
3. 浏览器打开 **http://127.0.0.1:4332/**。运行期间请保留终端窗口；可用 Ctrl+C 停止。页面只监听这台电脑。
4. 上传照片和生成规则建议不要求登录。Windows 的轮廓分析采用本地模型；Mac 支持 Apple Vision，并配有本地分析路径。自动生成试戴要有可用的 Codex CLI，并使用自己的 ChatGPT 账号登录；能否调用内置图像能力取决于当前 Codex 版本、账号和地区。发生限制时仍可查看方案，或在支持图像能力的 Codex 对话生成后导回。

要使用自动试戴，在终端运行 `npm install -g @openai/codex`，然后运行 `codex login`。登录后重新打开工作台。如果 Codex 装在自定义目录，可以在启动工作台前设置 `JQQ_CODEX_EXECUTABLE` 为可执行文件绝对路径。Windows 上应填写 `codex.exe` 的路径。[Codex CLI 安装说明](https://learn.chatgpt.com/docs/codex/cli)

如果双击没打开，请先进入工作台文件夹，再运行：

```sh
npm run start:workbench -- --open
```

端口有冲突时可设置环境变量 `JQQ_WORKBENCH_PORT`，例如设为 4333。源码编译与类型检查可执行 `npm ci`、`npm run type-check` 和 `npm run build:workbench`。

## 如何继续使用旧案例

工作台首次启动显示空白档案。照片、试戴图、案例、报告、登录资料不随包分发。生成的案例默认存于本项目的 `private-workspace/hair-consultation`，升级前请在本机备份。若要沿用旧档案，先关掉旧工作台，再运行对应命令：

Windows PowerShell：

```powershell
$env:JQQ_WORKBENCH_CASES = 'C:\你的旧项目\private-workspace\hair-consultation'
npm run start:workbench -- --open
```

macOS 终端：

```sh
JQQ_WORKBENCH_CASES="/你的旧项目位置/private-workspace/hair-consultation" npm run start:workbench -- --open
```

以上路径指向 **hair-consultation** 本身，里面包含多个案例目录。这不会复制或上传档案。操作细节见 [workbench/README.md](workbench/README.md)。
