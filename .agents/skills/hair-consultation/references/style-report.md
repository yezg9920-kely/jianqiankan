# 个人形象设计报告

用于用户说「做成个人形象报告」「整理成发型对比报告」「想拿给发型师看」。报告只排版本案例已经保存的素材和观察。若用户只需要选中款的沟通卡且已完成顾客确认，按 [案例记录](case-record.md) 走沟通卡脚本。工作台的自动当轮报告由其自身渲染，无需重复制作。

## 组织内容

- 开头给一个首选和一句对应的设计依据。理由用可见轮廓、实际发型和顾客偏好；没有顾客确认时只叫「首选方向」，不替顾客选定。
- 候选按「优先试／可尝试／本次放后」分组，或用顾客看得懂的2–3个方向。每格用编号、中文名称、一条区别和一条条件。不把仅有文字的设计方向算作已出图，不为凑数量复制原照。
- 同剪裁的发色、上衣色对照分别排，只有参考色块时写示意。不能凭滤镜或现场光线截屏断定季型、底色或真实染发效果。
- 角度不要求填齐。有该顾客真实角度素材才允许写「本人实拍」。从其他视角编辑推测的背面或侧面，用 `speculative` 明确标识，缺图就省略；多视图一致性仍应目检。
- 给发型师的是具体部位取舍和现场待核对事项，避免猜头发长度厘米数、配方、价格和技术可行性。用标题、图片和短句，不把提示词或运行日志放进顾客报告。

## 生成方式

从 [style-report-template.json](../assets/style-report-template.json) 复制一份到该顾客的私有案例目录：`case-report-v1.json`。填入内容与本案例相对路径（JSON 和素材须位于同一个案例根目录或其子目录；图片路径相对于 JSON 所在目录），再运行：

```sh
python3 scripts/render_style_report.py /案例路径/case-report-v1.json /案例路径/个人形象设计报告-v1.html
```

需要 Python 3.10+，仅用标准库。HTML 内嵌本地图片，不使用网络、外部字体或生图工具。浏览器打开可点图放大，按 Esc 关闭；用浏览器的「打印 → 保存为 PDF」可得到打印版。重复交付用新的文件名。HTML 内包含肖像，仍属于私有顾客资料。

## 数据字段

- `assets` 把短 ID 连到 `path`、`kind`、`label`，例如 `"p01": {"path":"assets/p01.png","kind":"preview","label":"A01 正面试戴"}`。种类是 `original`（本人实拍）、`baseline`（AI 整理基准照）、`preview`（AI 效果预览）、`speculative`（AI 推测视图）。只支持 PNG、JPEG、WebP。禁止绝对路径、URL、上级目录或通过符号链接跨案例。
- `baseline_asset` 可填实拍或已经整理的基准 ID；标识沿用素材的种类。`observations` 填 `feature`（部位）、`seen`（可见事实）、`design`（因此采用的取舍）。
- `tiers[].looks` 和色彩部分每个对象可用 `code/name/asset/label/reason/care`。没有图片可以留空；色彩条目还可用 `hex`（`#RRGGBB`）填写色块，衣色、发色各自注明比较条件。 `angles` 用 `asset/label`，`stylist_guide` 用 `part/instruction`。
- 空段落自动省略、缺失的已声明素材不会补图、未知的素材 ID 会被视为数据错误。实际图像来源靠上游核对；渲染器只保留字段的身份标签，不验证理发结果或本人相似度。
