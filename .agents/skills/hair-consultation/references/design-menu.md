# 发型候选的选择

这是结构参考库，不是固定四款，也不是流行排名。先满足当前长度、原生纹理、露额/刘海、扎发和打理限制，再挑彼此可区分的方向。每款至少把刘海、分线、两侧、顶部、耳周/后颈说清楚；看不到的区域保持待确认。

先按 [contour-personalization.md](contour-personalization.md) 观察本人，再从本库取设计材料。顾客说“更有型”时优先落实其明确审美方向，不能靠多生几张或换发色代替轮廓变化。每款写个人依据，保留脸型印象的不确定性；脸型、发质条件、打理需求、个人喜好一起参与设计。

首轮无需询问男生/女生。未指定时按照片里的外观呈现与现有发型选择男生、女生或中性设计目录，不能清楚判断就直接用中性目录。目录只影响候选结构，不能据此重画五官或记录顾客的真实性别身份；不把短发等同男生、长发等同女生。顾客一句“换个方向”即可覆盖初始目录。

首轮没有额外偏好时，优先安排同一发色下的几个结构方向。收到“都不合适”后，下一轮避开已拒绝结构，主动改变刘海覆盖、分线或外轮廓，结合已知限制生成另一组；不重复问基础资料。

| 可见长度与条件 | 可比较的方向 | 区分重点 |
| --- | --- | --- |
| 短发，接受整理前区 | 轻碎前向刘海 / 偏分 / 中分开口 / 低体积短碎 | 覆盖额头的范围、开口位置、前区长度；不能都画成同一种碎盖 |
| 短发，愿意明显变化 | 露额前刺 / 紧凑短寸 / 后梳 / 短狼尾 | 短寸需要剪短确认，狼尾需要现有后颈长度或标留长，后梳说明打理 |
| 齐肩或长发，保留整体长度 | 原轮廓轻整理 / 脸周层次 / 帘式长刘海 / 低层次厚发尾 | 前区覆盖、层次起点、发尾重量；不自动把天然卷拉直 |
| 中长发，接受剪短 | 锁骨轮廓 / 下颌波波 / 狼尾层次 / 短精灵 | 按实际可达长度筛选；扎发要求优先，不用短款覆盖限制 |

短发的旧 SC01 与 SC04 真实样张外观太相近。新规划中若同时用两款，需要明确：前者较长、眉上附近的分束前向刘海；后者明显更短、额头可见较多且顶部低。没有接受剪短时直接换一个结构方向。

不接受露额的顾客不用露额款；要扎发的顾客不默认剪去可扎区域。只能支持两款就出两款。性别不自动规定长度和颜色。

发色细选可从深棕、茶棕、冷棕中选最多三种；浅米金、雾玫瑰等只在明确要求大胆颜色时作为条件探索。按实际光照看色，不给屏幕色值当染发配方。

卷度细选围绕同一个剪裁：原生纹理、轻微起伏、明显弯卷；不借“自然蓬松”增加虚假发量。发质、能否烫染、是否需要漂浅由现场确认。
