# 照片自然优化与清晰排版

用户已要求：原照片拍得不理想时适当优化，同时把图片排得清楚、方便顾客选择。此要求适用于基准肖像和方案展示；不改变照片使用授权及本人核对要求。

## 基准只优化一次

先看真实正面和可用侧照，记录可见的拍摄问题：偏暗、过曝、色偏、硬阴影、杂乱背景、留白或取景不当、轻度不清晰。照片已经合适时克制处理，不为证明做过优化而加滤镜。

可做：去杂乱背景、保持本人肤色的曝光和白平衡整理、适度柔化强烈阴影、减轻临时痘痘和轻微倦态、保留纹理的轻度肤质整理、平面旋转与构图留白。保持镜框、眼睛、鼻嘴、下颌、脸宽、年龄感、胡须和稳定辨识特征。不得凭借“更好看”改脸型、放大眼睛、缩鼻、改笑容、拉长颈部、改变头骨或降低发际线。

若严重模糊、遮挡或大角度导致五官无法辨认，应说明缺失信息并补正面照。不能把生成的细节说成真实修复，不从侧照臆造正面再宣称高还原。输入允许范围内先做准备，不反复问已授权的自然整理。

基准提示词必须写清：真实原照是身份依据；移除原背景；自然曝光、肤色和浅色背景；自然轻度整理；保留真实面部几何和皮肤质感；不加妆，不制造模特写真。侧照只核对本人，不平均五官，不创造新视角。

基准完成后目检并记录实际优化、未解决的问题与本人确认状态。所有发型从同一基准分支，同时引用真实原照。后续只改变获准的头发，不逐款变肤色、脸型或美颜强度。

## 交付层次

1. 基准肖像：独立大图，注明“AI处理基准”。
2. 十二款总览：同样的人物大小、完整头发轮廓、醒目编号与中文名称。
3. 每页四款的大图：按自然分缝、清爽短发、卷度或留长等实际内容分组。方便看刘海、两侧与卷度，不用一张极长小字图承担全部阅读。
4. 本地图册：电脑默认三列，平板两列，手机一列；点击打开大图，可对照基准，查看完整原图。
5. 独立原件和实际提示词：保持可追溯，提示词在附件中，不挤进顾客选款界面。

编号、名称、图、差异、打理条件分层。说明不用生成过程或修错记录；这些放证据文件。推荐角标只表示视觉建议，不表示顾客已选定。备选和最终选择分开，不把本地临时勾选写成本人认可。

## 排版与验证

- 统一展示裁剪只能收掉多余背景和衣服，完整保留头顶、刘海、耳侧、后颈等当前需要比较的区域。不同头型或照片构图先调整裁剪参数，必要时用完整画幅，不能裁掉长发或卷发。
- `scripts/render_lookbook.py` 当前默认裁剪针对本次对齐的短发肖像批次；输入构图不同必须通过 `presentation-plan.json` 中的 `display_crop_normalized` 调整或选 `[0,0,1,1]` 保留全图。不可直接假定跨顾客通用。
- 文字不覆盖脸与发型。图中保留清楚的AI标识；原件中的标识被展示裁剪移到画外时，缩略图另加“AI效果预览”。
- 排版不得额外美颜、变色、过锐化、拉伸脸部或调用生图重画。原始PNG hash保持一致；缩略图另存，不能冒充生成原件。
- 检查总览和四款版的中文字体、标签、边距与截断；查看所有十二款，确认每款完整轮廓。
- 真实浏览器在手机和电脑尺寸验证：无横向溢出、图片完整解码、分类与放大有效，基准对照、备选、键盘关闭有效，无意外外部请求。只对本次变更做必要检查。
- 私有目录保存图片、图册、截图和记录。打包只包含本案例选定资产，清单hash核对，旧版保留；本人认可与理发师可行性保持真实状态。

自动排版 JPG 用 Python 3.10+ 与 Pillow。Mac 和 Windows 会尝试使用系统中文字体，也可将环境变量 `JQQ_CJK_FONT` 指向支持中文的字体文件。只需要可打印报告时，可使用不依赖 Pillow 的 [个人形象报告](style-report.md)。
