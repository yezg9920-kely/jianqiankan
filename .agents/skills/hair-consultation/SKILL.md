# 剪前看看 · 顾客发型设计

把顾客照片做成有个人依据、可按编号比较和继续调整的剪前方案。首次使用时说明正在使用本技能。

## 先选入口

- **在 Codex 对话里设计**：拿到真实照片，直接做轮廓观察与第一组候选。需要完整实操、图片提示词与结果记录时，读 [顾客咨询流程](references/consultation.md)。
- **在 Mac／Windows 工作台里生成或续做**：用户说打开工作台、查历史、继续某个案例、或给出 `执行剪前看看工作台任务 task-…` 时，读 [工作台使用与任务接力](references/workbench.md)。工作台可点击生成并自动回填，只有旧任务或明确走手动入口时才让用户复制任务号。
- **整理已有图片**：想发给顾客选款时，用 [图册排版](references/photo-quality-and-layout.md)；想要分级报告、首选多角度、发色或衣色对比时，用 [个人形象报告](references/style-report.md)。已有可用图片先复用，排版不重画人像。已选款要给发型师时，再读 [案例记录与沟通卡](references/case-record.md)。

## 顾客咨询的核心步骤

1. **先看真实原照。** 一张清楚、完整入镜的正面照即可开始。侧照只补对应视角，不能替换本人主照；未拍摄的角度要么省略，要么在明确需要示意时标注「AI 推测视图」。新顾客新建私有案例；历史案例先核对身份资料、实际图片及最近一轮，不覆盖旧图。
2. **从脸廓到剪法。** 记录可见的纵横印象、下颌到下巴的变化、眼周与发束的关系、两侧和发尾的重量，解释它们分别如何影响刘海、分线、层次、体积和边界。按 [轮廓观察](references/contour-personalization.md) 区分照片观察、个人偏好、建议和未知信息；不从外貌推断人格、肤色冷暖或精准尺寸。
3. **先保真，再出差异。** 保留真实原照为身份依据，按需要做干净背景和自然光线的基准；保留脸型、五官、眼镜、妆容、肤色与本人辨识特征。每款从同一案例底图独立分支，实际改变可见结构。标准完整对话轮目标是 12 款；用户指定数量或仅要单变量对照时采用相应规模，遵循工具和项目的实际批次限制。Mac／Windows 工作台新案例则默认做到一张基准加一到两款，已有基准每轮最多三款；其他候选标待制作，不把待制作当成出图。
4. **能选、能改、能找回。** 使用编号、原照对照和简单建议。用户没给硬限制时可先选低改动方向，保留发长与原生纹理；有明确风格或服务限制时优先采用。换组时改变轮廓方向并避开已拒绝款式；改款先尽量只改一个变量，另外保存新版。发色、卷度和衣色比较时固定无关变量。
5. **交付可核对的结果。** 若用户要当前趋势，查可核验来源；使用历史参考时说清访问日期，不能称为平台实时排行。参考方法、48 项设计提示词和发色审计见 [参考库使用指南](references/xhs-library-guide.md)。实际文件、图像来源、本人确认和理发师可行性各自记录；原件缺失不能用占位图冒充。

只使用本人或明确获准的照片。授权不清只暂停需发送人像的步骤，先完成本地准备。沿用已有授权的范围，不以一次上传推断公开或后续任意使用授权。人物照片、结果、报告和提示词实例存入私有工作目录，不进入 Skill、公开包或演示数据。本技能默认使用可用的 Codex 内置图像能力，不接收费模型 API，不代收账号凭据，也不把本机工作台开成公共服务。
